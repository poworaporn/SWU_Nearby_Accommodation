# น้องหมุดพาทัวร์ — ฉบับปรับภาพและการเคลื่อนไหว

ฉาก 8,500 บาทรักษามุมเดิมที่เห็น มศว ลดต้นไม้เล็กน้อย ภาพใหม่ใช้โทนฟ้า ครีม ส้ม เหลือง พื้นผิวสีวาดแบบ 2D เดียวกัน

การแก้ไข: เดินสลับแขนขาตามเฟรมและเวลาเสียง วางเท้าบนเส้นพื้นแต่ละฉาก; มอเตอร์ไซค์บนถนน; MRT ใต้ดิน; ห้องทีวีจอดำ วิวตึก; ห้องสีฟ้าไม่มีหอนาฬิกา; ฉากอโศกและรอในรถ; มุมสนามกีฬาและมุมสูง มศว; มาสคอตหลบพื้นที่ข้อมูล; ผลและการ์ดปัจจัยปรากฏทีละใบ; กราฟ OLS วาดเส้นและจุดตามลำดับ; ตัวเลขลบสีแดง; ระดับความเชื่อมั่น 90/95/99%; ปิดสองฉากโบกมือ/ไหว้และโน้ตบุ๊กแผนที่

ลำดับเสียงและภาพ: S → L → N → SL → SN → LN → SLN
ระยะเวลาเสียงรวม 8:53 โดยประมาณ ใช้เสียงบรรยายเดิมเรียงใหม่
เก็บตาราง Gretl ต้นฉบับ 21 ภาพ และค่าค่าสัมประสิทธิ์เดิม

## คำสั่งงานภาพ
ใช้เครื่องมือ imagegen แก้/สร้างภาพประกอบและเฟรมตัวละครจากภาพอ้างอิงเดิม: รักษาเอกลักษณ์ตัวละคร รูปทรง สีสดใส ลายเส้นบาง พื้นผิวสีกัวช์กระดาษ แยกวัตถุชัด ไม่มีภาพสมจริงหรือภาพ 3D; ฉากห้อง 8,500 ทีวีดำและวิวคอนโด; ที่พักสีฟ้าไม่มีแลนด์มาร์ก มศว; MRT อยู่ใต้ดิน; ภาพสนามกีฬาและมุมสูงตามภาพตัวอย่าง; สิ่งอำนวยความสะดวกแยกภาพตามตัวแปร; ฉากจบเก็บนักศึกษาและมาสคอตตามต้นแบบ

## ปรับตามภาพชุดล่าสุด
คืนตึกสีฟ้าที่มีวินและนักศึกษานั่งรอ คืนห้องนอนครีมกับเครื่องซักผ้าและมาสคอตอ่านหนังสือ คืนภาพคอนโดเทียบอพาร์ตเมนต์เดิม ขยายมาสคอตและปรับขนาดนักศึกษา/รปภในฉากแรก ใช้ภาพประตู มศว ตามรูปอ้างอิง เพิ่มภาพการเดินทางสามมิติของเวลา/เงิน/ช่วงเดินทางพร้อมมาสคอตร้องไห้และปั่นจักรยาน ลดกล่องผลเป็นการ์ดเล็ก จัด4–8ตัวแปรเป็นช่องภาพพร้อมท่าทางถือกระทะทอดไข่ อาบน้ำ ถือพัด วัดขนาด และถ่ายภาพ ใช้ภาพเต็มเมื่อมี1–3ผล เพิ่มแผนผังเส้นทางและมาสคอตเคลื่อนตามเส้น แผนผัง7รูปแบบครบตามต้นแบบ
