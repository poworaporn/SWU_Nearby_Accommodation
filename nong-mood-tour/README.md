# น้องหมุดพาทัวร์ — เว็บฉบับปรับภาพและการเคลื่อนไหว

นำโฟลเดอร์ `nong-mood-tour` ทั้งโฟลเดอร์ไปวางใน repository ของเว็บไซต์หลัก แล้ว commit และเปิด GitHub Pages ตามการตั้งค่าเดิม

เชื่อมจากหน้าเว็บหลักด้วยลิงก์:

```html
<a href="./nong-mood-tour/">ดูเรื่องเล่าผลวิจัยกับน้องหมุด</a>
```

หรือฝังในหน้าที่ต้องการ:

```html
<iframe src="./nong-mood-tour/" title="น้องหมุดพาทัวร์" style="width:100%;height:900px;border:0" allow="autoplay; fullscreen" allowfullscreen></iframe>
```

ไฟล์ HTML/JS/CSS เสียงรวม ภาพประกอบ เฟรมตัวละคร และ Gretl 21 ภาพอยู่ครบในโฟลเดอร์นี้ ใช้ path แบบ relative จึงย้ายไปอยู่ในโฟลเดอร์ย่อยได้
ต้องเปิดผ่านเว็บไซต์หรือ local web server เพื่อโหลด JSON; อย่าเปิด HTML ด้วย file:// โดยตรง
เสียงเริ่มเมื่อผู้ชมกดเล่นตามข้อจำกัดของเบราว์เซอร์มือถือ

ลำดับผลวิจัย S → L → N → SL → SN → LN → SLN
ระยะเวลาประมาณ 8:53 ใช้เสียงต้นฉบับเรียงใหม่
แพ็กเกจนี้ใช้ตัวเล่นภาพเคลื่อนไหวตามเวลาเสียง ไม่ใช้วิดีโอ story.mp4 รุ่นเก่า
