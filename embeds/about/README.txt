น้องหมุด — สองที่พัก สองคำตอบ
แตก ZIP แล้ววางโฟลเดอร์ nong-mood-cinema ทั้งโฟลเดอร์ในเว็บเดิม
เปิด index.html ผ่าน VS Code Live Server หรือเว็บโฮสต์
ตัวอย่างฝังในหน้าเว็บ:
<iframe src="./nong-mood-cinema/index.html?embed" title="น้องหมุดเล่าเรื่องที่พัก" style="width:100%;height:950px;border:0" allow="autoplay; fullscreen" allowfullscreen></iframe>
กดเริ่มหนึ่งครั้งเพื่อเริ่มเรื่องและอนุญาตเสียง
เสียงเล่าใช้เสียงภาษาไทยที่เบราว์เซอร์/อุปกรณ์มีให้ ไม่ใช่ไฟล์พากย์ที่บันทึกไว้ ถ้าไม่มีเสียงไทย ภาพยังเล่นได้และมีบทอ่านใต้ภาพ
แก้บทและเวลาใน film.js รูปอยู่ใน assets โปรดเก็บโครงสร้างโฟลเดอร์เดิม
ราคากับเวลาการเดินทางเป็นสถานการณ์สมมติประกอบการเล่าเรื่อง ไม่ใช่ผลประมาณการจากงานวิจัย
